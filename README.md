# hostel-complaint-system
The main objective of this project is to reduce manual paperwork and improve communication between students and hostel management. Students can track the status of their complaints in real time, while administrators can organize and prioritize issues effectively. The project improves transparency, saves time, and ensures faster resolution .
# Hostel Complaint Management System

This is a Flask-based web application developed to manage hostel complaints efficiently.

## Features
- Student Registration and Login
- Students can raise hostel complaints
- Students can view complaint status
- Admin login
- Admin can view all complaints
- Admin can update complaint status (Pending / In Progress / Solved)
- Admin can delete complaints

## Technologies Used
- Python
- Flask
- SQLite Database
- HTML, CSS
